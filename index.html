THE TRAVELLER’S FIELD GUIDE

Five ideas behind the journey.

Keep the railway in mind. These are the real computer components behind it.

01

One depot for everything

In von Neumann architecture, program instructions and data live in the same memory. Our depot has 32 addressed words. A word is interpreted as an instruction when the CPU fetches it, and as data when an operation reads it.

Try “Rewrite the route”: STORE replaces a future instruction with HALT. The CPU then executes that changed word.

02

A dispatcher and a workshop

The CPU contains a control unit, which decodes instructions and directs operations, and an arithmetic logic unit (ALU), which performs arithmetic and logic. This tiny CPU demonstrates addition, subtraction and a zero-based branch.

03

Fetch → decode → execute

Fetch: read the memory word at the program counter into the instruction register, then advance the counter. Decode: identify the operation and operand. Execute: perform the operation. Repeat until HALT.

The phase strip shows the next stage to run. A pending transfer keeps the current stage occupied.

04

Small, fast storage

PC selects the next instruction. IR holds the current instruction. ACC holds a working value. MAR holds a memory address and MDR holds a word moving to or from memory. Registers are inside the CPU; the depot represents main memory.

05

The shared connection

Instructions and data use the same CPU–memory connection. Limited transfer capacity can keep the CPU waiting: the von Neumann bottleneck. Select a longer memory transfer time and compare wait ticks for the same program.

The blue track carries address and control requests to memory. The orange track carries both instruction words and data values, including writes back to memory. Both serve the same shared depot. Input and output have separate terminals.

↗

A model you can understand

This is a deliberately small teaching CPU, not an emulator of a commercial processor. It uses decimal words, 32 memory cells, one accumulator and sequential execution. There are no caches, pipelines or operating system.

Instruction encoding: opcode × 100 + address. For example, LOAD 20 is 120; HALT is 900. Values range from −9999 to 9999; arithmetic overflow stops the run.

WELCOME ABOARD

Your first journey, in four stops.

  1. Choose a route. Start with the first delivery: 7 + 9.
  2. Press Step. Each click advances one clock tick. Follow the explanation below the map.
  3. Watch the registers. LOAD brings 7 into ACC; ADD changes it to 16; OUT delivers it.
  4. Experiment. Rewind a tick, slow memory down, or edit the timetable and assemble it.

The map is a teaching metaphor. The numbers in memory and the CPU state drive the simulation.
